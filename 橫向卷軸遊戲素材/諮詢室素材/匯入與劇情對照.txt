夢醒時分｜R4 諮詢室素材
依據：夢醒時分_遊戲腳本_1027.docx「十 R4 諮詢室與問題導向因應機台」

圖片製作與遊戲邏輯
本包是靜態圖片素材。NPC 選項、給予道具、機台操作、條件判斷與房間傳送，需另由編輯器與原 HTML 機台設定。
讀書計畫機台的圖片可作為啟動 HTML 介面的入口物件，不取代 HTML 內的排程功能。
所有日期與教師可協助時段均依劇本的相對描述呈現，沒有另加星期或時鐘時間。

通用匯入
物件設定 → 自訂圖片網址 → 上傳後的 PNG 直接網址。
縮放先設 1，依建議顯示尺寸.csv 設定寬高，並在場景預覽微調。
NPC、牆面公告、道具與機台入口通常不需勾選「可碰撞」。
背景地板不會自動產生碰撞，仍需設定平台或地面。
GitHub 上傳依使用者安排暫緩。

01 輔導老師
功能：協助區分感受、問題與資源。
對話標題：全部都來不及時，你要先做什麼？
A 每天讀得更久，把所有空格排滿 → 過載計畫碎片。
回饋：努力時間不等於可執行方案；睡眠、休息與注意力也是資源。
B 整理日期、落差、限制與可用協助 → 讀書計畫碎片。
回饋：先把模糊壓力定義成可判斷的問題，再比較方案。
C 先讓自己完全不焦慮，再開始準備 → 等待情緒歸零碎片。
回饋：情緒不必完全消失；可以一邊調節，一邊處理可控制的部分。

02 考試日程
資訊點：數學最先考，英文與理化時間較後。

03 教師時段表
資訊點：數學老師可在兩個放學時段協助。

04 過去錯題本
小物件：阿哲曾用分段整理改善成績。
功能：提醒玩家過去的因應經驗可作為資源。

05 讀書計畫機台
入口：開啟既有的自訂 HTML 讀書計畫介面。
題幹：距離大考尚有一週，將「全部都讀不完」轉換為可執行、可修正的計畫。
原劇本內曾列出本機 HTML 路徑，此包不連結該舊路徑，也不修改機台。
任務包括：數學、英文、理化複習，錯題整理，教師諮詢，睡眠，休息，運動／散步，與小晴談話。
核心檢查：數學優先安排在前三天；每日睡眠至少 7 小時；連續讀書後安排休息；使用資訊性支持；安排運動與情緒性支持；提交後依回饋至少修正一次。

06～08 第一次選項道具
分別對應輔導老師第一次互動 A、B、C。圖片名稱與劇本道具名稱一致。

09～11 機台完成後的選項道具
對話標題：這份計畫不保證你回到第一名。那麼，它的作用是什麼？
A 保證下一次一定成功 → 結果控制迷思。
回饋：問題導向因應提高行動的可執行性，但不能保證結果。
B 處理可以改變的部分，並依結果修正 → 問題導向因應。
回饋：阿哲不能控制最後名次，但可以決定下一步。
C 把焦慮完全消除 → 情緒歸零迷思。
回饋：讀書計畫處理的是可改變的壓力來源，不是要求情緒消失。

12 諮詢室背景
背景留出空間放置輔導老師、機台和三種線索。
場景邊緣的傢俱與植物為視覺陳設，不新增劇情條件。

道具在本段劇本中以選項結果和回饋為主；不要自行設定成戰鬥增益。
